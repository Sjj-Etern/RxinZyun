一、梯控引线定义：
1楼：橙-橙白
2楼：棕-绿白
3楼：绿-绿白
4楼：橙-绿白
5楼：棕-棕白
开门 橙-棕白
关门 黄-棕白

其它：
1. 绿-棕白：6楼
2. 棕-蓝白：7楼
3. 绿-蓝白：8楼
2. 棕-橙白：电话
3. 绿-棕白：电铃

梯控代码：components\BMP\EMISSION\emission.c\toFloor（去指定楼层）
    梯控里没有接入开、关门，如果需要，可以加入

二、电梯红外控制信号,32位（地址、命令各16位，高8位为数据，低8位是数据反码）
地址：0XFF00，上：0XE619，下：0XE718

三、继电器（5V输入）
GPIO_NUM_9,         // 继电器1
GPIO_NUM_10,        // 继电器2
GPIO_NUM_3,         // 继电器3
// GPIO_NUM_13,     // 继电器4
……定义其它引脚接入更多继电器端子
